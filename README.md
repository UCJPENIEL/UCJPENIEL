## 🤖 AI-Powered Outbound Calling System

Built an AI-enabled outbound voice application using Python and Microsoft Azure services.

The system can:

- Initiate outbound telephone calls
- Ask predefined questions automatically
- Convert text into speech
- Recognize spoken responses
- Transcribe answers
- Record calls
- Store responses in structured format
- Store recordings and generated audio
- Allow questions to be managed through an administrative interface

### Technologies

This project represents an important direction in my work:
